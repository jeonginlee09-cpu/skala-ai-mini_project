# 교재 정합성·검색·후속 질문·제출 검증

사용자의 “위 내용 적용”에 따라 앞서 논의한 변경을 직접 실행합니다. 기존 feature/conditional-reviewer 브랜치를 이어 쓰며 원본 백업·과거 실측은 수정하지 않습니다.

## 적용 범위

- 관련성·인용 검사는 유지하고 런북 두 개 고정 제한을 제거합니다. 현재 여섯 문서가 전체 후보 상한입니다. 문서 개수로 정답을 강제하지 않습니다.
- 이전 사용자 메시지에서 명시한 대상만 후속 질문에 연결합니다. 단일 지시 대상이 모호하면 추가 질문하며, 이전 측정값은 재사용하지 않습니다.
- 기존 세션·게이트·반복 제한을 신규 기능으로 소개한 표현을 바로잡습니다. Writer 3회·Reviewer 2회 상한과 실패 보류는 유지합니다.
- 쓰지 않는 운영 그래프의 옛 키워드 분류기를 평가 도구로 이동하고, 호출되지 않는 추출 함수를 제거합니다. 원본·이전 측정·필요한 legacy 경로는 보존합니다.

## 작업·검증

- [ ] 1. 검색 제한 변경의 실패 테스트 → 구현 → 통과
- [ ] 2. 후속 질문·모호성·세션 격리·새 조회의 실패 테스트 → 구현 → 통과
- [ ] 3. 전체 Python·화면 회귀 검사 및 변경 코드 다섯 축 검토
- [ ] 4. 원본과 최종 코드의 동일 질문 실제 비교, 새 기능 실제 사례, LangSmith 재조회
- [ ] 5. 변경 근거·한계·평가표·발표 자료를 최종 상태에 맞춰 정리
- [ ] 6. 재현 명령·파일 링크·비밀값 제외·불필요 파일 검토 및 로컬 커밋

## 집중 검토할 실패 조건

세 증상 이상, 모호한 복수 대상, 명시한 새 대상 우선, 다른 세션의 정보 혼입, 과거 수치를 현재값으로 인용하는 오류입니다. 스트리밍 전용 검사는 추가하지 않습니다. 실제 조치 실행·사람 승인·실제 청구액·독립 정답률은 완료된 것으로 표시하지 않습니다.
