# messages / updates 적용과 세 버전 재측정

사용자가 승인한 범위: 사진의 텍스트·노드 업데이트 구분을 현재 최적화본에 적용하고, 기존 과제·최적화본·수정본을 같은 조건으로 다시 측정합니다. 스트리밍 전용 검증 항목·새 테스트는 추가하지 않습니다.

## 설계

- 기존 `langchain-core`의 `BaseChatModel` 어댑터가 OpenAI의 실제 SSE 조각을 `AIMessageChunk`로 중계합니다. `messages` 채널은 일반 대화 노드만 화면에 전달합니다. 추가 SDK·LLM 재호출·문장 쪼개기 연출은 없습니다.
- `updates`는 노드 결과를 처리합니다. 코드가 직접 실행하는 MCP/RAG의 즉시 진행 알림은 `custom`으로 전달합니다. 교재의 LLM tool-call 요청과 실제 도구 실행을 혼동하지 않습니다.
- 도구 실행별 시작/종료/실패 이벤트에 호출 ID를 부여합니다. 노드 완료 상태는 남기되 화면에서는 같은 결과를 두 번 표시하지 않습니다.
- 동기 분류·계획은 작업 스레드로 분리합니다. 장애 보고서의 ID 선택·조건 검수·검수 후 렌더링·검색 정책은 변경하지 않습니다.
- 기존 60 Python / 4 UI 회귀 검사를 실행합니다. 전용 스트리밍 테스트·TTFT 지표는 추가하지 않습니다.
